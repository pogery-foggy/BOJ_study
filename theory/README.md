# BOJ Theory Map

`ALGORITHM_STUDY_ORDER.md`와 각 알고리즘의 `CORE.md`, 연결된 본인 코드를 한 화면에서 읽는 로컬 학습 웹입니다.

## 실행

1. `start_theory_web.cmd`를 더블클릭합니다.
2. 브라우저가 자동으로 열립니다.
3. 서버를 끄려면 열린 명령 창에서 `Ctrl+C`를 누릅니다.

VS Code 터미널에서는 저장소 루트를 기준으로 다음 명령을 실행해도 됩니다.

```powershell
node theory/server.mjs
```

기본 주소는 `http://127.0.0.1:8765/`입니다. 이미 사용 중인 포트라면 서버가 빈 포트를 자동으로 선택해 실제 주소를 출력합니다.

> `index.html`을 직접 더블클릭하면 브라우저의 `file://` 보안 제한 때문에 Markdown과 코드 파일을 읽을 수 없습니다. 반드시 실행 파일이나 위 명령으로 시작하세요.

## 기능

- `ALGORITHM_STUDY_ORDER.md`의 9단계·62개 알고리즘을 원래 순서로 표시
- 알고리즘 검색: 이름, 본문, 문제 번호와 연결된 코드 파일명까지 검색
- `CORE.md`에서 본인 `.cpp` 코드를 내부 코드 뷰어로 열기
- 코드 화면에서 같은 번호의 문제 설명·입력·출력·제한을 열고 풀이로 복귀
- 로컬 `BOJ/<구간>/<번호>.md`가 없는 문제는 백준 원문으로 연결
- 앱의 `뒤로`, 브라우저 뒤로/앞으로, `학습 순서`, 이전/다음 알고리즘 제공
- 코드 화면에서 원래 알고리즘 노트로 바로 복귀
- 복원 완료 상태, 테마와 코드 줄바꿈 설정을 브라우저에 로컬 저장
- Markdown 또는 코드 수정 후 우측 상단 `↻` 버튼으로 최신 파일 다시 읽기
- 외부 패키지, CDN, 인터넷 연결 없이 동작

## 원본 파일 처리

웹은 원본 Markdown과 코드를 읽기만 합니다. `CORE.md`, `BOJ` 문제 문서나 `.cpp`를 변경하거나 이동하지 않습니다. 기존 `theory` 폴더의 다음 파일도 그대로 유지됩니다.

- `24445.cpp`
- `day1_subset.cpp`
- `power함수구현.cpp`
