# 이분 탐색 핵심

## 1. 한 문장 기억

정렬된 값 자체를 찾거나, 정답 후보 `x`에 대한 단조 판정 `ok(x)`의 경계 하나를 찾는다.

## 2. 언제 꺼내는가

- 정렬된 배열에서 특정 값·처음 위치·마지막 위치를 찾는다.
- “길이를 `x`로 하면 N개 이상 가능한가?”처럼 후보가 커질수록 참/거짓이 한 번만 바뀐다.
- 답의 범위는 큰데 후보 하나를 O(N) 안팎으로 검증할 수 있다.

## 3. 핵심 상태 / 불변식

- 닫힌 구간형에서 답은 탐색 전 `[lo, hi]` 안에 있다.
- 최댓값 탐색: `ok(mid)`면 `answer=mid`, 더 큰 쪽 `lo=mid+1`.
- 최솟값 탐색: `ok(mid)`면 `answer=mid`, 더 작은 쪽 `hi=mid-1`.
- `mid = lo + (hi-lo)/2`; 합계와 범위는 보통 `long long`이다.

## 내 코드 스타일 C++ 최소 구현 골격

스타일 근거: [1654.cpp](./1654.cpp)의 전역 `l, r, mid, answer`, 고정 배열, 판정을 `solve()`의 반복문 안에서 바로 계산하는 구조를 축약했다.

```cpp
#define MAX_N 10000

int K, N, k_arr[MAX_N], max_stick = -1;
long long l, r, mid, answer, rotn;

void init() {
    cin >> K >> N;
    for (int i = 0; i < K; i++) {
        cin >> k_arr[i];
        max_stick = max_stick > k_arr[i] ? max_stick : k_arr[i];
    }
    l = 1;
    r = max_stick;
}

void solve() {
    while (l <= r) {
        mid = (l + r) >> 1;
        rotn = 0;
        for (int i = 0; i < K; i++)
            rotn += k_arr[i] / mid;

        if (rotn >= N) {
            l = mid + 1;
            answer = mid > answer ? mid : answer;
        } else
            r = mid - 1;
    }
    cout << answer;
}
```

원본의 흐름은 유지하되, 잘라 만든 개수 `rotn`은 합이 커질 수 있으므로 골격에서는 `long long`으로 넓혔다. K번째 수처럼 처음 참인 값을 찾을 때는 [1300.cpp](./1300.cpp)의 `p(mid)`처럼 판정을 함수로 빼고 참이면 `answer=mid; r=mid-1`로 움직인다.

## 5. 빈 화면 구현 순서

1. 무엇을 후보 `x`로 둘지 정한다.
2. `ok(x)`가 어느 방향으로 단조인지 말로 써 본다.
3. 최소·최대 정답 중 어느 경계를 찾는지 정한다.
4. 안전한 `lo`, `hi`와 자료형을 잡는다.
5. `ok(mid)`의 참일 때 이동 방향을 쓴다.
6. 답이 최솟값·최댓값과 같은 경계 사례로 검산한다.

## 6. 자주 틀리는 지점

- `lo=0`으로 두고 길이 문제에서 0으로 나누는 실수.
- `ok`의 참/거짓 방향과 포인터 이동을 반대로 쓰는 실수.
- `N*N`, `lo+hi`, 개수 합계를 `int`로 계산하는 실수.
- 중복값이 있을 때 단순 일치 탐색과 첫/마지막 경계 탐색을 혼동하는 실수.
