# 완전 탐색 핵심

## 1. 한 문장 기억

가능한 후보의 수를 먼저 계산하고 충분히 작다면, 모든 후보를 빠짐없이 생성해 직접 검증한다.

## 2. 언제 꺼내는가

- 입력 제한상 경우의 수 `N`, `N^2`, `2^N`, 작은 순열이 시간 안에 들어온다.
- 최적화 규칙보다 후보 생성과 검증이 더 단순하고 확실하다.
- 높이 0..256처럼 후보 범위가 문제에서 작게 고정되어 있다.

## 3. 핵심 상태 / 불변식

- 바깥 반복문은 가능한 후보를 정확히 한 번씩 방문한다.
- 안쪽 검증은 그 후보의 비용·가능 여부만 계산하며 다른 후보의 상태를 섞지 않는다.
- 최적답 갱신 기준과 동률 규칙을 한 조건에 명시한다.

## 내 코드 스타일 C++ 최소 구현 골격

스타일 근거: [18111.cpp](./18111.cpp)의 전역 2차원 배열과 `answer[2]`, `init()`에서 최솟값 초기화, 후보 높이를 바깥 반복문에서 전부 확인하는 구조를 축약했다.

```cpp
int arr[501][501];
int N, M, B, answer[2];

void init() {
    cin >> N >> M >> B;
    for (int i = 0; i < N; i++)
        for (int j = 0; j < M; j++)
            cin >> arr[i][j];
    answer[0] = 2147483647;
}

void solve() {
    for (int h = 0; h <= 256; h++) {
        int b = 0, d = 0;
        for (int i = 0; i < N; i++) {
            for (int j = 0; j < M; j++) {
                int y = arr[i][j] - h;
                if (y > 0)
                    d += arr[i][j] - h;
                else if (y < 0)
                    b += h - arr[i][j];
            }
        }
        if (b <= B + d) {
            int t = d * 2 + b;
            if (answer[0] >= t) {
                answer[0] = t;
                answer[1] = h;
            }
        }
    }
    cout << answer[0] << " " << answer[1];
}
```

동률일 때 높은 높이를 남기는 습관도 원본처럼 `>=`와 오름차순 후보 순회로 표현했다. 두 개를 제외하는 문제는 [2309.cpp](./2309.cpp)처럼 `for (i)`, `for (j=i+1)`만 돈다.

## 5. 빈 화면 구현 순서

1. 후보가 총 몇 개인지 계산해 시간복잡도를 확인한다.
2. 후보를 중복 없이 열거하는 반복문 범위를 쓴다.
3. 후보 하나의 가능 여부와 비용을 독립 함수처럼 계산한다.
4. 불가능 후보를 제외한다.
5. 최소/최대와 동률 우선순위를 갱신 조건에 넣는다.
6. 첫 후보, 마지막 후보, 답이 여러 개인 경우를 시험한다.

## 6. 자주 틀리는 지점

- 시간복잡도를 세지 않고 무작정 순열까지 생성하는 실수.
- 후보별 누적 변수 초기화를 바깥에서 한 번만 하는 실수.
- 조합에서 `j=i` 또는 `j=0`으로 시작해 같은 경우를 중복 검사하는 실수.
- 동률일 때 더 높은 높이 등 문제의 두 번째 정렬 기준을 빼먹는 실수.
