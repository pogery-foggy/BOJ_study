# 배낭 DP 핵심 복원 노트

## 한 문장 기억

**물건을 하나씩 보면서 용량 `w`의 최선 값을 “안 넣기”와 “넣기” 중 더 좋은 값으로 갱신한다.**

## 언제 꺼내는가

- 각 선택에 비용·무게가 있고 총 한도가 있다.
- 가치 최대화, 비용 최소화, 경우의 수를 구한다.
- 각 항목을 한 번만 쓰는지(0/1), 여러 번 쓰는지(완전), 개수가 제한되는지가 명확하다.

## 핵심 상태와 불변식

- 2차원: `dp[i][w]` = 앞의 `i`개 물건만 보고 용량 `w` 이하에서 얻는 최대 가치.
- 1차원 0/1: 물건 `i` 처리 중 `dp[w]`를 읽을 때 아직 이전 물건들만 반영돼 있어야 한다.
- 그래서 0/1 배낭은 `w`를 내림차순, 무한 사용은 오름차순으로 돈다.
- 비용 최소화형은 가치/효과를 축으로 뒤집어 상태를 잡을 수도 있다.

## C++ 최소 구현 골격

[12865.cpp](./12865.cpp)의 2차원 전이를 메모리 `O(K)`로 줄인 0/1 골격이다.

```cpp
vector<long long> dp(K + 1, 0);

for (auto [weight, value] : item) {
    for (int w = K; w >= weight; --w) { // 0/1: 반드시 역순
        dp[w] = max(dp[w], dp[w - weight] + value);
    }
}
cout << dp[K];
```

경우의 수를 세며 동전을 여러 번 쓸 수 있다면 순서가 반대다.

```cpp
vector<long long> ways(K + 1);
ways[0] = 1;
for (int coin : coins)
    for (int w = coin; w <= K; ++w) // 완전 배낭: 정순
        ways[w] += ways[w - coin];
```

## 빈 화면 구현 순서

1. 한도 축이 무게인지 비용인지, `dp` 값이 가치인지 경우의 수인지 쓴다.
2. 항목을 한 번/무한/제한 횟수 중 무엇으로 쓰는지 확인한다.
3. `dp[0]`과 도달 불가능 상태를 초기화한다.
4. “안 넣기 vs 넣기” 전이를 먼저 2차원 식으로 적는다.
5. 1차원으로 줄일 때 반복 방향을 결정한다.
6. 답이 `dp[K]`인지 `max(dp[0..K])`인지 확인한다.

## 자주 틀리는 지점

- 0/1 배낭을 정순으로 갱신해 같은 물건을 여러 번 쓰는 것.
- 정확히 용량 `w`를 채우는 상태와 `w` 이하 상태를 구분하지 않는 것.
- 도달 불가능 상태를 0으로 두어 음수 가치/최소 비용 전이를 오염시키는 것.
- 경우의 수에서 물건-용량 반복문 순서 때문에 조합과 순열이 바뀌는 것.
- 가치 합을 `int`에 담아 넘치는 것.
