# LCS 핵심 복원 노트

## 한 문장 기억

**두 접두사의 마지막 문자가 같으면 대각선에 1을 더하고, 다르면 위와 왼쪽 중 긴 공통 부분수열을 물려받는다.**

## 언제 꺼내는가

- 두 문자열/수열의 순서는 유지하되 원소를 건너뛸 수 있다.
- 공통 부분수열의 길이 또는 실제 수열이 필요하다.
- 삽입·삭제 기반 편집 문제를 공통으로 남길 부분의 길이로 바꿀 수 있다.

## 핵심 상태와 불변식

- `dp[i][j]`: `A[0..i)`와 `B[0..j)`의 LCS 길이.
- `A[i-1] == B[j-1]`이면 `dp[i-1][j-1] + 1`.
- 다르면 `max(dp[i-1][j], dp[i][j-1])`.
- 복원 중 대각선 이동만 실제 문자를 답에 추가한다.

## C++ 최소 구현 골격

[9252.cpp](./9252.cpp)처럼 방향을 저장해 실제 LCS까지 복원한다.

```cpp
vector<vector<int>> dp(n + 1, vector<int>(m + 1));
vector<vector<char>> dir(n + 1, vector<char>(m + 1));

for (int i = 1; i <= n; ++i) {
    for (int j = 1; j <= m; ++j) {
        if (A[i - 1] == B[j - 1]) {
            dp[i][j] = dp[i - 1][j - 1] + 1;
            dir[i][j] = 'D';
        } else if (dp[i - 1][j] > dp[i][j - 1]) {
            dp[i][j] = dp[i - 1][j]; dir[i][j] = 'U';
        } else {
            dp[i][j] = dp[i][j - 1]; dir[i][j] = 'L';
        }
    }
}

string ans;
for (int i = n, j = m; i && j; ) {
    if (dir[i][j] == 'D') {
        ans += A[i - 1];
        --i; --j;
    } else if (dir[i][j] == 'U') {
        --i;
    } else {
        --j;
    }
}
reverse(ans.begin(), ans.end());
```

## 빈 화면 구현 순서

1. 두 수열 앞에 길이 0인 행과 열을 만든다.
2. `i,j`가 가리키는 문자는 각각 `i-1,j-1`임을 고정한다.
3. 같을 때 대각선, 다를 때 위/왼쪽 전이를 작성한다.
4. 길이만 필요하면 두 행으로 압축한다.
5. 문자열이 필요하면 방향 또는 전체 `dp`를 남겨 뒤에서부터 복원한다.
6. 입력 크기가 매우 크면 bitset 또는 Hirschberg 폴더의 변형을 검토한다.

## 자주 틀리는 지점

- 부분 문자열(연속)과 부분수열(건너뛰기 가능)을 혼동하는 것.
- 문자 인덱스와 DP 인덱스의 `-1`을 빼먹는 것.
- 복원 결과를 뒤집지 않는 것.
- 동률일 때 어느 방향을 택해도 길이는 맞지만, 특정 사전순 답이 필요하면 별도 규칙이 필요함.
- 메모리 `O(NM)`을 입력 제한 확인 없이 잡는 것.
