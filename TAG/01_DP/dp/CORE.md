# 동적 계획법(DP) 핵심 복원 노트

## 한 문장 기억

**중복되는 작은 문제의 답을 `dp[상태]`에 확정해 두고, 이미 확정된 상태만 이용해 더 큰 상태를 만든다.**

## 언제 꺼내는가

- 같은 조건의 부분 문제가 여러 경로에서 반복된다.
- 최솟값·최댓값·경우의 수·가능 여부를 묻고, 선택 뒤에 남는 문제가 같은 모양이다.
- 문제의 진행 순서와 함께 기억해야 할 정보가 작다. 예: `현재 위치`, `마지막 선택`, `남은 자원`.

가장 먼저 `dp[i][j]가 정확히 무엇인가?`를 한 문장으로 적는다. 예를 들어 RGB 거리 풀이의 `dp[i][color]`는 **i번째 집을 color로 칠했을 때 1..i의 최소 비용**이다.

## 핵심 상태와 불변식

- 상태: 답을 결정하는 데 필요한 정보만 남긴다.
- 전이: 현재 상태로 들어오는 모든 합법적인 이전 상태를 비교한다.
- 초기값: 가장 작은 문제의 답은 직접 채운다.
- 계산 순서: 전이가 참조하는 상태가 반드시 먼저 계산되어 있어야 한다.
- 복원: 값만으로 이전 상태를 판별하거나 `parent/state_from`을 함께 저장한다.

## 내 코드 스타일 C++ 최소 구현 골격

스타일 근거: [1149.cpp](./1149.cpp)의 전역 `arr`/`dp`/`idx` 배열, 색 두 개를 `pair`로 찾아가는 반복문, 1부터 시작하는 인덱스, `init()`과 `solve()` 분리를 그대로 축약했다.

```cpp
#include <algorithm>
#include <iostream>
#include <utility>
using namespace std;

int arr[1001][4];
int dp[1001][4];
int N;
pair<int, int> idx[6] = {
    {0, 0}, {0, 0}, {0, 0}, {1, 2}, {1, 3}, {2, 3}
};

void init() {
    cin >> N;
    for (int i = 1; i <= N; i++) {
        for (int j = 1; j <= 3; j++) {
            cin >> arr[i][j];
        }
    }
    dp[1][1] = arr[1][1];
    dp[1][2] = arr[1][2];
    dp[1][3] = arr[1][3];
}

void solve() {
    for (int i = 2; i <= N; i++) {
        for (int j = 1; j <= 3; j++) {
            dp[i][j] = min(dp[i - 1][idx[6 - j].first],
                           dp[i - 1][idx[6 - j].second]);
            dp[i][j] += arr[i][j];
        }
    }
    cout << min({dp[N][1], dp[N][2], dp[N][3]});
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    init();
    solve();
    return 0;
}
```

경로까지 필요하면 [12852.cpp](./12852.cpp)처럼 `dp[next] == dp[cur] - 1`인 전이를 역으로 찾거나, 갱신할 때 `parent[next] = cur`를 기록한다.

## 빈 화면 구현 순서

1. `dp[...] = ...`라는 상태 정의를 주석 한 줄로 쓴다.
2. 최종 답이 어느 상태인지 먼저 정한다.
3. 기저 상태와 불가능 상태(`INF`, `-INF`, `false`)를 채운다.
4. 한 상태에서 가능한 선택을 식으로 나열한다.
5. 의존 방향에 맞춰 반복문 또는 메모이제이션 DFS를 작성한다.
6. 경우의 수라면 모듈러, 비용이라면 자료형과 `INF`를 확인한다.
7. 경로가 필요하면 부모를 저장하거나 등식으로 역추적한다.

## 자주 틀리는 지점

- 상태 뜻이 중간에 바뀌거나, 필요한 정보 하나를 상태에서 빼는 경우.
- 최솟값 배열을 0으로 두어 아직 계산하지 않은 상태가 정답처럼 보이는 경우.
- 같은 배열을 갱신하면서 이번 단계 값을 다시 읽어 0/1 선택을 무한 선택처럼 만드는 경우.
- `int` 누적합 오버플로와 `INF + cost` 오버플로.
- 복원 시 동률 처리와 종료 조건을 빠뜨리는 경우.
