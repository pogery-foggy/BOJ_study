# 트리 순회 핵심 복원 노트

## 한 문장 기억

**트리는 두 정점 사이 경로가 하나뿐이므로, 부모 방향만 막고 한 번 순회하면 거리·부모·깊이·서브트리를 동시에 정할 수 있다.**

## 언제 꺼내는가

- 간선이 `N-1`개인 연결 그래프에서 두 정점의 거리나 경로를 구한다.
- 부모·깊이·서브트리 크기·리프 수가 필요하다.
- 일반 그래프보다 유일 경로 성질을 직접 이용할 수 있다.

## 핵심 상태와 불변식

- 루트를 정하면 루트가 아닌 모든 정점은 부모가 정확히 하나다.
- `depth[v] = depth[parent[v]] + 1`.
- 가중치가 없으면 BFS/DFS로 처음 도달한 경로가 유일한 경로다.
- 후위 처리에서는 모든 자식의 값이 끝난 뒤 현재 서브트리 값을 계산한다.

## C++ 최소 구현 골격

[2644.cpp](./2644.cpp)의 BFS 거리 계산을 일반화했다.

```cpp
vector<int> parent(n + 1, -1), depth(n + 1, -1);
queue<int> q;
depth[root] = 0;
q.push(root);

while (!q.empty()) {
    int u = q.front(); q.pop();
    for (int v : tree[u]) {
        if (v == parent[u]) continue;
        parent[v] = u;
        depth[v] = depth[u] + 1;
        q.push(v);
    }
}
```

## 빈 화면 구현 순서

1. 연결이고 간선 수가 `N-1`인지, 가중치가 있는지 확인한다.
2. 인접 리스트에 무방향 간선을 양쪽으로 넣는다.
3. 목적에 맞는 루트를 정한다.
4. 부모 또는 방문 배열로 되돌아가는 간선을 막는다.
5. 진입 시 부모·깊이·누적 거리를 기록한다.
6. 서브트리 정보는 자식 재귀가 끝난 뒤 합친다.

## 자주 틀리는 지점

- 무방향 간선을 한쪽만 넣는 것.
- 부모로 돌아가는 간선을 막지 않아 무한 순회하는 것.
- 트리가 아닌 그래프에도 유일 경로 성질을 적용하는 것.
- 깊은 사슬 트리에서 재귀 스택이 넘치는 것.
- 여러 질의의 경로를 매번 순회해 시간 제한을 넘기고 LCA 전처리를 놓치는 것.
