# Union-Find(DSU) 핵심 복원 노트

## 한 문장 기억

**각 집합을 대표 정점 하나로 표현하고, `find`로 대표를 찾고 `unite`로 두 대표를 합쳐 연결 여부를 거의 상수 시간에 관리한다.**

## 언제 꺼내는가

- 간선/관계가 추가되면서 두 대상이 같은 집합인지 반복해서 묻는다.
- 연결 요소를 합치되 실제 경로나 이동 순서는 필요하지 않다.
- Kruskal MST에서 사이클 여부를 빠르게 판정한다.

## 핵심 상태와 불변식

- `parent[root] == root`인 정점이 집합의 대표다.
- 같은 집합의 모든 정점은 `find` 결과가 같다.
- 경로 압축은 `find` 중 지나온 정점을 대표에 직접 붙인다.
- 크기/랭크가 작은 트리를 큰 트리 밑에 붙여 높이를 억제한다.

## 내 코드 스타일 C++ 최소 구현 골격

스타일 근거: [1043.cpp](./1043.cpp)의 전역 부모 배열 `p`, `find_parent()`/`Union()`/`p_check()` 함수 분리, 재귀 경로 압축과 1부터 직접 초기화하는 방식을 보존했다.

```cpp
int p[51];
int N;

int find_parent(int a) {
    if (a == p[a])
        return a;
    return p[a] = find_parent(p[a]);
}

void Union(int a, int b) {
    a = find_parent(a);
    b = find_parent(b);
    if (a == b) return;
    p[b] = a;
}

bool p_check(int a, int b) {
    a = find_parent(a);
    b = find_parent(b);
    return a == b;
}

void init_parent() {
    for (int i = 1; i <= N; i++)
        p[i] = i;
}
```

## 빈 화면 구현 순서

1. 모든 `parent[i]=i`, `size[i]=1`로 초기화한다.
2. 대표면 자신을 반환하는 `find` 기저를 쓴다.
3. 재귀 반환을 부모에 대입해 경로를 압축한다.
4. `unite` 시작에서 두 입력을 대표로 바꾼다.
5. 대표가 같으면 아무것도 하지 않는다.
6. 크기/랭크 기준으로 한 대표를 다른 대표에 붙인다.

## 자주 틀리는 지점

- 원소 `a,b`를 대표로 바꾸기 전에 직접 부모를 잇는 것.
- 초기화를 `0..N` 중 일부만 하는 것.
- union 뒤 대표가 특정 번호일 것이라고 가정하는 것.
- 집합 분리가 필요한 문제에 DSU를 억지로 쓰는 것(기본 DSU는 삭제/분리 불가).
- [1043.cpp](./1043.cpp)처럼 모든 참가자와 모든 진실 보유자를 이중 비교할 때, 대표 집합 하나로 합쳐 더 간단히 만들 수 있음을 놓치는 것.
