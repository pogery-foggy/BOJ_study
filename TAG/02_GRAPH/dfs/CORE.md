# DFS 핵심 복원 노트

## 한 문장 기억

**한 갈래를 끝까지 내려가며 방문 표시하고, 되돌아오면서 연결 요소·경로·서브트리 정보를 완성한다.**

## 언제 꺼내는가

- 연결 요소의 개수나 영역 크기를 구한다.
- 경로 존재, 사이클, 백트래킹, 트리의 부모/서브트리 정보를 구한다.
- “현재 경로에 포함되었는가”가 중요한 문제를 푼다.

## 핵심 상태와 불변식

- `visited[u]`는 같은 탐색에서 이미 처리하기 시작한 정점임을 뜻한다.
- 정점에 들어오자마자 방문 표시한 뒤 이웃을 재귀 호출한다.
- 연결 요소 문제는 아직 방문하지 않은 유효 정점마다 DFS를 한 번 시작하고 답을 1 늘린다.
- 경로 탐색에서는 전역 방문과 현재 경로 방문(`inPath`)을 구분해야 한다.

## C++ 최소 구현 골격

[1012.cpp](./1012.cpp)의 격자 연결 요소 구조다.

```cpp
void dfs(int y, int x) {
    visited[y][x] = true;
    for (int d = 0; d < 4; ++d) {
        int ny = y + dy[d], nx = x + dx[d];
        if (ny < 0 || ny >= n || nx < 0 || nx >= m) continue;
        if (!cell[ny][nx] || visited[ny][nx]) continue;
        dfs(ny, nx);
    }
}

int components = 0;
for (int y = 0; y < n; ++y)
    for (int x = 0; x < m; ++x)
        if (cell[y][x] && !visited[y][x]) {
            dfs(y, x);
            ++components;
        }
```

## 빈 화면 구현 순서

1. 정점과 간선이 무엇인지, 격자라면 이동 방향을 정한다.
2. DFS 진입 직후 방문 처리한다.
3. 이웃마다 범위/간선 존재/미방문 조건을 검사한다.
4. 재귀 후 무엇을 모아야 하는지(크기, low 값, 성공 여부)를 정한다.
5. 전체 정점을 돌며 새 탐색을 시작해야 하는지 확인한다.
6. 입력 크기가 크면 명시적 `stack`으로 바꾼다.

## 자주 틀리는 지점

- 재귀 호출 뒤 방문 처리해 무방향 간선에서 서로 재호출하는 것.
- 여러 테스트케이스 사이 배열/인접 리스트를 초기화하지 않는 것.
- 그래프가 비연결인데 한 정점에서만 시작하는 것.
- 단순 방문과 현재 재귀 스택 방문을 혼동하는 것.
- 깊이가 수십만인데 재귀를 그대로 사용해 스택 오버플로가 나는 것.
