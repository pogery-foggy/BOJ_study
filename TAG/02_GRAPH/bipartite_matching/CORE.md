# 이분 매칭 핵심 복원 노트

## 한 문장 기억

**왼쪽 정점마다 증강 경로를 찾아, 이미 차지한 오른쪽 정점의 상대를 다른 곳으로 밀어낼 수 있으면 매칭 수를 하나 늘린다.**

## 언제 꺼내는가

- 두 종류의 대상 사이에서 조건을 만족하는 일대일 짝을 최대한 많이 만든다.
- “사람-일”, “행-열”, “수의 두 그룹”처럼 그래프를 좌우 집합으로 나눌 수 있다.
- 특정 짝을 고정한 뒤 나머지가 완전 매칭되는지 반복 검사한다(소수 쌍 유형).

## 핵심 상태와 불변식

- 골격의 `connect[v]`: 오른쪽 정점 `v`와 현재 짝인 왼쪽 정점, 없으면 1-based 정점과 겹치지 않는 `0`.
- 한 번의 증강 시도에서 `seen[v]`는 같은 오른쪽 정점을 재귀적으로 다시 파고들지 않게 한다.
- `dfs(u)`는 `u`를 포함하도록 현재 매칭을 재배치할 수 있으면 참이다.
- 성공한 증강 경로는 매칭 간선/비매칭 간선을 번갈아 뒤집어 크기를 정확히 1 늘린다.

## 내 코드 스타일 C++ 최소 구현 골격

현재 [1017.cpp](./1017.cpp)는 0바이트이므로 이분 매칭에 대한 사용자 구현 근거는 없다.

스타일 근거: 같은 그래프 재귀 탐색 코드인 [2150.cpp](../scc/2150.cpp)의 전역 인접 리스트·전역 배열·`dfs()`·범위 기반 순회를 따랐다. 이분 매칭 알고리즘 논리 자체는 표준 Kuhn 골격이다.

```cpp
#define MAX_N 1001

vector<int> edge[MAX_N];
int connect[MAX_N];
bool is_visit[MAX_N];
int L, R;

bool dfs(int cur) {
    for (auto next : edge[cur]) {
        if (is_visit[next])
            continue;
        is_visit[next] = true;
        if (connect[next] == 0 || dfs(connect[next])) {
            connect[next] = cur;
            return true;
        }
    }
    return false;
}

void solve() {
    int answer = 0;
    for (int i = 1; i <= L; i++) {
        for (int j = 1; j <= R; j++)
            is_visit[j] = false;
        if (dfs(i)) answer++;
    }
    cout << answer;
}
```

## 빈 화면 구현 순서

1. 좌우 집합을 명확히 나누고 간선 조건을 만든다.
2. 오른쪽 기준 `connect` 배열을 `0`으로 초기화한다. 0-based 정점을 쓰면 대신 `-1`을 쓴다.
3. 한 왼쪽 정점에서 갈 수 있는 오른쪽을 순회한다.
4. 비어 있거나 기존 상대를 다른 곳으로 옮길 수 있으면 매칭한다.
5. 왼쪽 정점마다 `seen`을 새로 초기화해 증강을 시도한다.
6. 완전 매칭 문제라면 결과가 필요한 좌측 정점 수와 같은지 확인한다.

## 자주 틀리는 지점

- 일반 그래프를 근거 없이 값의 홀짝만으로 이분 그래프라고 가정하는 것.
- `seen`을 전체 알고리즘에서 한 번만 초기화해 뒤의 증강 경로를 막는 것.
- 고정한 짝을 그래프/매칭에서 제거하지 않고 다시 사용하게 하는 것.
- 중복 값이 있는 문제에서 값 자체를 정점 ID로 써 서로 다른 원소를 합치는 것.
- 큰 그래프에서 Kuhn의 `O(VE)`가 충분한지 확인하지 않는 것(Hopcroft–Karp 검토).
