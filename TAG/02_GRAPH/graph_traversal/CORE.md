# 그래프 순회 핵심 복원 노트

## 한 문장 기억

**현재 상태에서 정해진 다음 상태로 계속 이동하되, 목표 도달이나 재방문을 종료 조건으로 삼는다.**

## 언제 꺼내는가

- 각 정점의 다음 정점이 하나뿐인 함수형 그래프를 따라간다.
- 최단 거리보다 단순 도달 여부와 이동 횟수가 중요하다.
- 일반 BFS/DFS보다 “포인터 따라가기”가 문제 구조를 더 직접 표현한다.

## 핵심 상태와 불변식

- `next[u]`: 정점 `u`에서 유일하게 이동할 다음 정점.
- 반복 시작 시 `cur`까지의 이동 횟수가 `count`다.
- 목표에 닿으면 성공, 방문한 정점에 다시 닿으면 이후도 반복되므로 실패다.
- 테스트케이스마다 방문 배열을 초기화한다.

## 내 코드 스타일 C++ 최소 구현 골격

스타일 근거: [11558.cpp](./11558.cpp)의 전역 `is_visit`/`arr` 배열, `cnt`/`cur` 변수명, `init()`에서 테스트케이스 상태를 초기화하고 `solve()`에서 `while`로 다음 정점을 따라가는 구조를 보존했다.

```cpp
bool is_visit[10001];
int arr[10001];
int N;

void init() {
    cin >> N;
    for (int i = 1; i <= N; i++) {
        is_visit[i] = false;
        cin >> arr[i];
    }
}

void solve() {
    int cnt = 0;
    int cur = 1;
    while (!is_visit[cur] && cur != N) {
        is_visit[cur] = true;
        cnt++;
        cur = arr[cur];
    }
    if (cur == N)
        cout << cnt << "\n";
    else
        cout << "0\n";
}
```

## 빈 화면 구현 순서

1. 정점마다 다음 정점이 정확히 하나인지 확인한다.
2. `cur=start`, `steps=0`으로 둔다.
3. 목표와 재방문을 반복 조건 또는 루프 안에서 검사한다.
4. 현재 정점을 방문 처리한다.
5. 다음 정점으로 이동하고 횟수를 늘린다.
6. 성공/사이클 종료의 출력 규칙을 분리한다.

## 자주 틀리는 지점

- 이동 전/후 중 언제 횟수를 증가시키는지 섞어 1 차이가 나는 것.
- 목표 정점을 방문 처리한 뒤에만 확인해 종료를 늦추는 것.
- 테스트케이스 간 방문 배열을 지우지 않는 것.
- 정점마다 간선이 여러 개인데도 단일 `next` 순회로 단순화하는 것.
