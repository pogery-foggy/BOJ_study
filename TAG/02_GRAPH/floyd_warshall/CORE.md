# Floyd–Warshall 핵심 복원 노트

## 한 문장 기억

**중간 정점으로 `1..k`만 허용한 모든 쌍 최단 거리를, 정점 `k`를 안 쓰는 경우와 쓰는 경우 중 작은 값으로 갱신한다.**

## 언제 꺼내는가

- 모든 정점 쌍의 최단 거리나 도달 가능성이 필요하다.
- 정점 수가 보통 수백 이하라 `O(N^3)`을 감당할 수 있다.
- 키 순서처럼 `a→b` 또는 `b→a` 도달 여부를 모두 알아야 한다.

## 핵심 상태와 불변식

- `dist[i][j]`: 지금까지 허용한 중간 정점만 이용한 `i→j` 최소 비용.
- 바깥 반복문이 반드시 중간 정점 `k`다.
- 전이: `dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`.
- 도달성만 필요하면 `reach[i][j] |= reach[i][k] && reach[k][j]`로 바뀐다.

## C++ 최소 구현 골격

현재 폴더의 `2458.cpp`는 0바이트라 사용자 구현을 복원할 근거가 없다. 아래는 다시 작성할 수 있는 기본 골격이다.

```cpp
const long long INF = (1LL << 60);
vector<vector<long long>> dist(n + 1, vector<long long>(n + 1, INF));
for (int i = 1; i <= n; ++i) dist[i][i] = 0;
for (auto [u, v, w] : edges) dist[u][v] = min(dist[u][v], (long long)w);

for (int k = 1; k <= n; ++k)
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= n; ++j) {
            if (dist[i][k] == INF || dist[k][j] == INF) continue;
            dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
        }
```

## 빈 화면 구현 순서

1. 거리 문제인지 단순 도달성 문제인지 정한다.
2. 대각선은 0/참, 나머지는 `INF`/거짓으로 초기화한다.
3. 중복 간선이면 최솟값을 넣는다.
4. 반복문을 `k → i → j` 순서로 작성한다.
5. `INF`끼리 더하지 않도록 검사한다.
6. 결과에서 도달 불가, 음수 사이클, 순서 확정 등 문제별 판정을 한다.

## 자주 틀리는 지점

- `k`를 가장 바깥에 두지 않아 “허용된 중간 정점” 불변식이 깨지는 것.
- 자기 자신 거리를 0으로 초기화하지 않는 것.
- 중복 간선을 마지막 입력으로 덮어쓰는 것.
- `INF + INF` 오버플로.
- `O(N^3)`이 가능한 크기인지 확인하지 않는 것.
