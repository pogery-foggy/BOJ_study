# 위상 정렬 핵심 복원 노트

## 한 문장 기억

**선행 조건이 모두 사라진 진입차수 0 정점부터 꺼내면, 모든 간선의 앞 정점이 뒤 정점보다 먼저 오는 순서를 얻는다.**

## 언제 꺼내는가

- 작업·과목·건물 사이의 선행 관계가 있는 DAG를 처리한다.
- 가능한 순서, 순서의 유일성, 사이클 여부를 구한다.
- 선행 작업의 최댓값/경우의 수를 DAG DP로 전파한다.

## 핵심 상태와 불변식

- `indegree[v]`: 아직 처리하지 않은 선행 간선 수.
- 큐에는 현재 모든 선행 조건이 끝난 정점만 들어간다.
- 정점 `u`를 처리할 때 `u→v` 간선을 제거한 효과로 `indegree[v]--`한다.
- 처리한 정점 수가 `N`보다 작으면 사이클이 있다.
- [1005.cpp](./1005.cpp)의 `finish[v]`는 `v`까지 완료하는 최소 필요 시간의 최댓값이다.

## C++ 최소 구현 골격

```cpp
queue<int> q;
vector<long long> finish(n + 1);
for (int i = 1; i <= n; ++i) {
    finish[i] = duration[i];
    if (indegree[i] == 0) q.push(i);
}

int processed = 0;
while (!q.empty()) {
    int u = q.front(); q.pop();
    ++processed;
    for (int v : graph[u]) {
        finish[v] = max(finish[v], finish[u] + duration[v]);
        if (--indegree[v] == 0) q.push(v);
    }
}
if (processed < n) /* cycle */;
```

## 빈 화면 구현 순서

1. 간선을 선행 작업→후행 작업 방향으로 넣는다.
2. 간선을 넣을 때 후행 정점 진입차수를 증가시킨다.
3. 진입차수 0을 모두 큐에 넣는다.
4. 하나를 꺼내 답 순서/DP 값을 처리한다.
5. 모든 다음 정점의 진입차수를 줄이고 0이면 큐에 넣는다.
6. 처리 개수로 사이클을 검사한다.
7. 사전순 최소가 필요하면 큐 대신 최소 힙을 쓴다.

## 자주 틀리는 지점

- 간선 방향과 진입차수 증가 대상을 반대로 잡는 것.
- DP를 진입차수가 0이 된 순간에만 한 번 갱신해 다른 선행 경로를 놓치는 것.
- 여러 테스트케이스에서 큐·진입차수·인접 리스트를 비우지 않는 것.
- 사이클인데 일부 순서만 출력하고 성공으로 처리하는 것.
- 동시에 가능한 정점의 선택 규칙(사전순/유일성)을 무시하는 것.
