# BFS 핵심 복원 노트

## 한 문장 기억

**간선 비용이 모두 같으면 큐에서 거리 순으로 상태가 나오므로, 처음 방문한 순간의 거리가 최단 거리다.**

## 언제 꺼내는가

- 무가중 그래프·격자에서 최소 이동 횟수를 구한다.
- 시작점이 여러 개인 확산 문제를 푼다.
- 위치 외에 벽 파괴 횟수, 열쇠, 낮/밤 같은 작은 상태를 함께 탐색한다.

## 핵심 상태와 불변식

- 큐에는 단순 정점이 아니라 **미래가 달라지는 정보 전체**를 상태로 넣는다.
- `dist[state]`는 시작점에서 그 상태까지의 최소 간선 수다.
- 큐에 넣는 순간 방문 처리하면 같은 상태가 중복 삽입되지 않는다.
- 여러 시작점은 모두 거리 0으로 먼저 큐에 넣는다.

## 내 코드 스타일 C++ 최소 구현 골격

스타일 근거: [7576.cpp](./7576.cpp)의 전역 `map`/`visited`/방향 배열, `queue<pair<pair<int, int>, int>>`, `valid()`과 `bfs()` 함수 분리, `q.front().first`로 좌표를 꺼내는 방식을 축약했다.

```cpp
queue<pair<pair<int, int>, int>> q;
int map[1001][1001];
bool visited[1001][1001];
int dx[] = {0, 0, 1, -1};
int dy[] = {1, -1, 0, 0};
int N, M;

bool valid(int x, int y) {
    if (x < 0 || x >= N) return false;
    if (y < 0 || y >= M) return false;
    return true;
}

void bfs() {
    pair<pair<int, int>, int> cur;
    while (!q.empty()) {
        cur = q.front();
        q.pop();
        int x = cur.first.first;
        int y = cur.first.second;

        for (int i = 0; i < 4; i++) {
            int nx = x + dx[i];
            int ny = y + dy[i];
            if (valid(nx, ny) && map[nx][ny] == 0 && !visited[nx][ny]) {
                visited[nx][ny] = true;
                q.push({{nx, ny}, cur.second + 1});
            }
        }
    }
}
```

이 골격의 `map[nx][ny] == 0`은 [7576.cpp](./7576.cpp)에서 아직 익지 않은 토마토만 다음 상태로 넣는 문제 전용 조건이다. 일반 격자에서는 그 자리를 문제의 통과 가능 조건으로 바꾼다. 자원이 붙으면 `visited[x][y][broken][parity]`처럼 상태 차원을 늘린다. [16933.cpp](./16933.cpp)은 위치·남은 벽 파괴 수·낮/밤을 함께 큐에 넣는 예다. [2178.cpp](./2178.cpp)의 좌표 디버그 출력은 골격에 복제하지 않았다.

## 빈 화면 구현 순서

1. 한 상태를 완전히 식별하는 필드를 적는다.
2. `dist`를 미방문 값 `-1`로 채운다.
3. 모든 시작 상태를 방문 처리 후 큐에 넣는다.
4. 큐에서 꺼내 가능한 다음 상태를 만든다.
5. 범위·장애물·미방문 여부를 검사한다.
6. 방문 처리는 `push`와 동시에 하고 거리를 `+1`한다.
7. 목표를 처음 발견/꺼낼 때 종료 가능한지 확인한다.

## 자주 틀리는 지점

- 큐에서 꺼낼 때 방문 처리해 중복 상태가 폭증하는 것.
- 위치만 방문 처리해 서로 다른 자원 상태를 합치는 것.
- 시작 거리 0/1과 출력 거리의 기준을 섞는 것.
- 밤에 기다리기처럼 “제자리 이동”도 간선이라는 사실을 놓치는 것.
- 탐색용 디버그 출력을 남기는 것([2178.cpp](./2178.cpp)에 좌표 출력이 남아 있으니 복습 때 특히 확인).
