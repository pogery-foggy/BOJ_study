# BFS 핵심 복원 노트

## 한 문장 기억

**간선 비용이 모두 같으면 큐에서 거리 순으로 상태가 나오므로, 처음 방문한 순간의 거리가 최단 거리다.**

## 언제 꺼내는가

- 무가중 그래프·격자에서 최소 이동 횟수를 구한다.
- 시작점이 여러 개인 확산 문제를 푼다.
- 위치 외에 벽 파괴 횟수, 열쇠, 낮/밤 같은 작은 상태를 함께 탐색한다.

## 핵심 상태와 불변식

- 큐에는 단순 정점이 아니라 **미래가 달라지는 정보 전체**를 상태로 넣는다.
- `dist[state]`는 시작점에서 그 상태까지의 최소 간선 수다.
- 큐에 넣는 순간 방문 처리하면 같은 상태가 중복 삽입되지 않는다.
- 여러 시작점은 모두 거리 0으로 먼저 큐에 넣는다.

## C++ 최소 구현 골격

[2178.cpp](./2178.cpp)의 격자 BFS를 거리 배열 중심으로 정리한 형태다.

```cpp
vector<vector<int>> dist(n, vector<int>(m, -1));
queue<pair<int, int>> q;
dist[sy][sx] = 0;
q.push({sy, sx});

while (!q.empty()) {
    auto [y, x] = q.front(); q.pop();
    for (int d = 0; d < 4; ++d) {
        int ny = y + dy[d], nx = x + dx[d];
        if (ny < 0 || ny >= n || nx < 0 || nx >= m) continue;
        if (blocked[ny][nx] || dist[ny][nx] != -1) continue;
        dist[ny][nx] = dist[y][x] + 1;
        q.push({ny, nx});
    }
}
```

자원이 붙으면 `dist[y][x][broken][parity]`처럼 상태 차원을 늘린다. [16933.cpp](./16933.cpp)은 위치·남은 벽 파괴 수·낮/밤을 함께 큐에 넣는 예다.

## 빈 화면 구현 순서

1. 한 상태를 완전히 식별하는 필드를 적는다.
2. `dist`를 미방문 값 `-1`로 채운다.
3. 모든 시작 상태를 방문 처리 후 큐에 넣는다.
4. 큐에서 꺼내 가능한 다음 상태를 만든다.
5. 범위·장애물·미방문 여부를 검사한다.
6. 방문 처리는 `push`와 동시에 하고 거리를 `+1`한다.
7. 목표를 처음 발견/꺼낼 때 종료 가능한지 확인한다.

## 자주 틀리는 지점

- 큐에서 꺼낼 때 방문 처리해 중복 상태가 폭증하는 것.
- 위치만 방문 처리해 서로 다른 자원 상태를 합치는 것.
- 시작 거리 0/1과 출력 거리의 기준을 섞는 것.
- 밤에 기다리기처럼 “제자리 이동”도 간선이라는 사실을 놓치는 것.
- 탐색용 디버그 출력을 남기는 것([2178.cpp](./2178.cpp)에 좌표 출력이 남아 있으니 복습 때 특히 확인).
