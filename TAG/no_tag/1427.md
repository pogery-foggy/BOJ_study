# 1427번: 소트인사이드

- 시간 제한: 2 초
- 메모리 제한: 128 MB
- 파일명 기반 분류 (공식 알고리즘 분류 아님): 없음
- 아카이브: [Wayback Machine에서 보기](https://web.archive.org/web/20260416065527/https://www.acmicpc.net/problem/1427)

## 문제

배열을 정렬하는 것은 쉽다. 수가 주어지면, 그 수의 각 자리수를 내림차순으로 정렬해보자.

## 입력

첫째 줄에 정렬하려고 하는 수 N이 주어진다. N은 1,000,000,000보다 작거나 같은 자연수이다.

## 출력

첫째 줄에 자리수를 내림차순으로 정렬한 수를 출력한다.
