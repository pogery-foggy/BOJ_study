# 문자열 처리 핵심

## 1. 한 문장 기억

문자열 문제는 문자를 하나씩 읽으며 지금 어느 구간에 있는지와 직전까지 확정된 결과만 유지한다.

## 2. 언제 꺼내는가

- 단어 뒤집기, 빈도 계산, 진법 변환, 팰린드롬처럼 문자 단위 규칙을 구현한다.
- 특정 패턴의 연속 등장 횟수를 선형으로 센다.
- 공백을 포함한 한 줄 전체를 상태에 따라 처리해야 한다.

## 3. 핵심 상태 / 불변식

- 인덱스 `i` 이전 문자는 모두 처리 완료다.
- 스택/버퍼에는 아직 출력하지 않은 현재 단어만 들어 있다.
- 패턴 탐색에서는 `correct`가 현재 위치까지 연속된 패턴 조각의 수를 뜻한다.

## 4. C++ 최소 구현 골격

```cpp
string s;
getline(cin, s);
string word;
bool inTag = false;

auto flushReverse = [&]() {
    reverse(word.begin(), word.end());
    cout << word;
    word.clear();
};

for (char c : s) {
    if (c == '<') {
        flushReverse();
        inTag = true;
        cout << c;
    } else if (c == '>') {
        inTag = false;
        cout << c;
    } else if (inTag) {
        cout << c;
    } else if (c == ' ') {
        flushReverse();
        cout << ' ';
    } else {
        word += c;
    }
}
flushReverse();
```

## 5. 빈 화면 구현 순서

1. 입력이 토큰인지 공백 포함 한 줄인지 정한다.
2. 문자를 읽을 때 필요한 상태를 열거한다.
3. 상태 전환 문자와 일반 문자를 분리한다.
4. 미완성 버퍼를 비우는 함수를 먼저 만든다.
5. 한 번의 선형 순회로 처리한다.
6. 문자열 끝에서 남은 버퍼를 반드시 처리한다.

## 6. 자주 틀리는 지점

- `cin >>` 뒤 바로 `getline`해 남은 개행을 읽는 실수.
- `s[i+1]`, `s[i+2]`를 경계 확인 없이 읽는 실수.
- 공백이나 태그 시작 직전에 쌓인 단어를 출력하지 않는 실수.
- 마지막 단어를 루프 밖에서 비우지 않는 실수.
