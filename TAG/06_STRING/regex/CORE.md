# 정규 표현식 핵심

## 1. 한 문장 기억

문자열 전체가 간단한 문법을 만족하는지는 패턴으로 선언하고 `regex_match`로 한 번에 검증한다.

## 2. 언제 꺼내는가

- 허용 문자, 선택 구간, 반복 횟수처럼 문자열 규칙이 정규 언어로 짧게 표현된다.
- 부분 문자열 찾기·치환이 필요하며 직접 파서를 쓰는 것보다 패턴이 명확하다.
- 단, 태그 중첩처럼 스택 상태가 필요한 문법은 정규식만으로 끝내지 않는다.

## 3. 핵심 상태 / 불변식

- `regex_match`는 문자열 전체, `regex_search`는 일부 일치를 본다.
- `^`, `$`는 시작과 끝, `[]`는 문자 집합, `?`는 0/1회, `+`는 1회 이상이다.
- 반복 검색 시 다음 입력은 `match.suffix()`로 줄어들어야 한다.

## 내 코드 스타일 C++ 최소 구현 골격

스타일 근거: [9342.cpp](./9342.cpp)의 전역 `string S`, `init()` 입력, `solve()` 안의 `regex re`와 `regex_match` 분기, 테스트케이스 반복 구조를 축약했다.

```cpp
string S;

void init() { cin >> S; }

void solve() {
    regex re("(^[A-F]?A+F+C+[A-F]?$)");

    if (regex_match(S, re))
        cout << "Infected!\n";
    else
        cout << "Good\n";
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    int T;
    cin >> T;
    for (int testcase = 0; testcase < T; testcase++) {
        init();
        solve();
    }
    return 0;
}
```

부분 검색이 필요한 경우에는 [4828.cpp](./4828.cpp)처럼 `smatch tag_str`를 두고 `copy_line = tag_str.suffix()`로 다음 검색 범위를 줄인다.

## 5. 빈 화면 구현 순서

1. 자연어 규칙을 시작·중간·끝 토큰으로 나눈다.
2. 각 토큰의 허용 문자와 반복 횟수를 적는다.
3. 전체 검증이면 패턴 양끝에 `^`, `$`를 둔다.
4. 원시 문자열 리터럴 `R"(...)"`로 패턴을 쓴다.
5. 최소 길이, 최대 반복, 허용되지 않은 문자로 시험한다.
6. 중첩 대응이 있으면 별도 스택/파서를 결합한다.

## 6. 자주 틀리는 지점

- 전체 검증에 `regex_search`를 써서 일부만 맞아도 통과시키는 실수.
- C++ 문자열 이스케이프와 정규식 이스케이프를 이중으로 놓치는 실수.
- `*`(0회 허용)와 `+`(1회 이상)를 혼동하는 실수.
- 중첩 태그 짝맞춤을 정규식 하나로 해결하려는 실수.
