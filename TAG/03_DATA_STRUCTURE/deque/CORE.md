# Deque 기억 복원

## 한 문장 기억

양끝을 모두 열어 두고, 앞에서는 유효기간을 지우고 뒤에서는 앞으로 쓸모없는 후보를 지운다.

## 언제 꺼내는가

- 슬라이딩 윈도 최솟값/최댓값을 매 위치마다 구할 때
- 실제 배열을 뒤집지 않고 읽는 방향만 바꿀 때
- 양쪽 끝에서 삽입·삭제가 일어나는 시뮬레이션일 때

## 핵심 상태/불변식

- 모노톤 덱에는 현재 창 안의 인덱스만 있고, 값은 앞에서 뒤로 단조롭게 유지된다.
- 덱의 맨 앞은 현재 답이다.
- 방향 시뮬레이션에서는 `rev`가 "논리적 앞"이 실제 `front`인지 `back`인지만 나타낸다.

## C++ 최소 구현 골격

```cpp
deque<pair<int, int>> dq; // {값, 인덱스}, 값 오름차순

for (int i = 0; i < n; ++i) {
    while (!dq.empty() && dq.front().second < i - L + 1)
        dq.pop_front();                  // 창 밖
    while (!dq.empty() && dq.back().first > a[i])
        dq.pop_back();                   // 새 값보다 커서 다시 답이 될 수 없음
    dq.push_back({a[i], i});
    cout << dq.front().first << ' ';
}
```

방향만 뒤집는 명령은 다음 두 줄이 핵심이다.

```cpp
if (cmd == 'R') rev = !rev;
else if (!rev) dq.pop_front();
else dq.pop_back();
```

## 빈 화면 구현 순서

1. 덱 원소에 값만 필요한지, 만료 확인용 인덱스도 필요한지 정한다.
2. `front`에서 만료 원소를 제거한다.
3. `back`에서 단조성을 깨는 후보를 제거한다.
4. 새 원소를 넣고 `front`를 답으로 쓴다.
5. 역방향 명령은 실제 `reverse` 대신 불리언 하나로 처리한다.

## 자주 틀리는 지점

- 길이 `L`인 창의 왼쪽 경계는 `i - L + 1`이다.
- 최솟값에서 같은 값도 지울지(`>=`) 남길지(`>`)는 인덱스 수명과 함께 결정한다.
- 삭제 전에 `empty()`를 검사한다.
- 테스트케이스마다 덱, 파싱 버퍼, 방향 플래그를 모두 초기화한다.
