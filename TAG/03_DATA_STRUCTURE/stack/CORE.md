# Stack 기억 복원

## 한 문장 기억

가장 최근에 열린 일부터 닫거나, 아직 답을 못 찾은 후보를 뒤에서부터 제거할 때 스택을 쓴다.

## 언제 꺼내는가

- 괄호·문자열 축약·후위 표기식처럼 중첩 구조를 처리할 때
- 각 원소의 다음 큰 값/이전 작은 값을 선형 시간에 찾을 때
- 되돌아갈 상태나 최근 후보만 필요할 때

## 핵심 상태/불변식

- 오큰수에서 오른쪽부터 볼 때 스택에는 현재 값보다 큰 후보만 남고 위쪽이 가장 가까운 후보이다.
- 연산자 스택에는 아직 출력하지 않은 연산자만 있고, 현재 연산자보다 우선순위가 높거나 같은 것은 먼저 빠진다.
- 모노톤 스택은 "무엇을 단조롭게 유지하는지"를 값/인덱스로 명시한다.

## C++ 최소 구현 골격

```cpp
stack<int> st; // 오른쪽 후보 값
for (int i = n - 1; i >= 0; --i) {
    while (!st.empty() && st.top() <= a[i]) st.pop();
    answer[i] = st.empty() ? -1 : st.top();
    st.push(a[i]);
}
```

중위→후위 변환의 연산자 부분:

```cpp
while (!op.empty() && op.top() != '(' &&
       priority(op.top()) >= priority(cur)) {
    out += op.top(); op.pop();
}
op.push(cur);
```

## 빈 화면 구현 순서

1. 스택에 값, 인덱스, 연산자 중 무엇을 넣을지 정한다.
2. 스택이 유지할 단조성 또는 괄호 불변식을 한 줄로 적는다.
3. 새 원소가 왔을 때 쓸모없는 top을 `while`로 제거한다.
4. 제거 후 top에서 답을 얻고 새 원소를 push한다.
5. 입력 종료 후 남은 연산자/후보 처리를 한다.

## 자주 틀리는 지점

- 같은 값이 답이 될 수 있는지에 따라 `<`와 `<=`가 달라진다.
- 인덱스 거리가 필요하면 값이 아니라 인덱스를 저장한다.
- `)`를 만났을 때 `(`까지 pop한 뒤 `(` 자체도 버린다.
- 왼쪽 결합 연산자는 같은 우선순위도 먼저 pop하지만 거듭제곱 같은 오른쪽 결합은 다르다.
