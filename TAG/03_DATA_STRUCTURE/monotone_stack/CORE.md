# Monotone Stack 기억 복원

## 한 문장 기억

새 원소 때문에 앞으로 답이 될 수 없는 후보를 즉시 버려, 각 원소가 한 번 들어가고 한 번만 나오게 한다.

## 언제 꺼내는가

- 각 위치의 이전/다음 작은 값 또는 큰 값을 찾을 때
- 한 값을 최솟값으로 유지할 수 있는 최대 구간을 찾을 때
- 히스토그램, 부분배열 최솟값×합처럼 경계가 핵심일 때

## 핵심 상태/불변식

- 스택에는 아직 오른쪽 경계를 만나지 않은 인덱스만 있다.
- 증가 스택이라면 아래에서 위로 값이 엄격히 증가한다.
- `L[i]`, `R[i]`는 `a[i]`보다 작은 첫 위치이며 유효 구간은 `(L[i], R[i])`다.

## C++ 최소 구현 골격

```cpp
vector<int> st;
for (int i = 1; i <= n; ++i) {
    while (!st.empty() && a[st.back()] >= a[i]) st.pop_back();
    L[i] = st.empty() ? 0 : st.back();
    st.push_back(i);
}

st.clear();
for (int i = n; i >= 1; --i) {
    while (!st.empty() && a[st.back()] >= a[i]) st.pop_back();
    R[i] = st.empty() ? n + 1 : st.back();
    st.push_back(i);
}

long long sum = prefix[R[i] - 1] - prefix[L[i]];
answer = max(answer, a[i] * sum);
```

## 빈 화면 구현 순서

1. `a[i]`가 최솟값/최댓값으로 버틸 경계를 찾는지 정한다.
2. 같은 값을 누가 소유할지 정하고 pop 조건 `>` 또는 `>=`를 고른다.
3. 왼쪽부터 `L`, 오른쪽부터 `R`을 구한다.
4. 더미 경계를 `0`, `n+1`로 둔다.
5. 누적합 또는 구간 길이와 결합해 후보 답을 계산한다.

## 자주 틀리는 지점

- 값이 아니라 경계 인덱스가 필요하면 인덱스를 저장한다.
- 양쪽 모두 같은 값을 남기면 동일 구간을 빠뜨리거나 중복 계산할 수 있다.
- 유효 구간 끝은 `L+1`, `R-1`이다.
- 곱과 누적합은 `long long`으로 올린다.
