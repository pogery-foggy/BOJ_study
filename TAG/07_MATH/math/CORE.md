# 수학적 모델링 핵심

## 1. 한 문장 기억

반복 과정을 그대로 돌리기 전에, 답을 결정하는 식·주기·몫과 나머지를 찾아 O(1) 또는 작은 반복으로 바꾼다.

## 2. 언제 꺼내는가

- 날짜, 이동 횟수, 점수, 나머지처럼 식 하나로 정리되는 문제다.
- 같은 상태가 일정 주기로 반복된다.
- 시뮬레이션하면 크지만 마지막 단계만 예외 처리하면 된다.

## 3. 핵심 상태 / 불변식

- 한 주기 뒤 상태가 같다면 `횟수 % 주기`만 남겨도 결과가 같다.
- 마지막 날에는 내려가지 않는 식처럼 반복 한 묶음과 종료 단계를 분리한다.
- 정수 올림 나눗셈은 양수에서 `(x+d-1)/d`로 표현한다.

## 4. C++ 최소 구현 골격

```cpp
long long ceilDiv(long long x, long long d) {
    return (x + d - 1) / d; // x>=0, d>0
}

// 매일 up, 밤에 down, 목표 height: 마지막 날의 up을 먼저 제외
long long days = ceilDiv(height - up, up - down) + 1;

// 주기 문제
int state = initial;
for (long long i = 0; i < count % period; ++i) {
    state = nextState(state);
}
```

## 5. 빈 화면 구현 순서

1. 작은 입력 몇 개를 손으로 전개한다.
2. 한 번 반복할 때 실제 순변화와 종료 순간을 분리한다.
3. 반복 상태라면 주기 길이를 찾는다.
4. 나눗셈의 올림/내림 조건을 식으로 정한다.
5. 자료형 범위를 확인한 뒤 구현한다.
6. 딱 나누어떨어지는 경우와 한 번 더 필요한 경우를 대조한다.

## 6. 자주 틀리는 지점

- 마지막 단계에도 감소·복귀가 일어난다고 계산하는 실수.
- 올림 나눗셈을 부동소수점 `ceil`에 맡겨 정밀도 문제를 만드는 실수.
- 나머지 0의 출력 표현이 10 같은 별도 값인 문제를 놓치는 실수.
- 음수에도 `(x+d-1)/d` 공식을 그대로 쓰는 실수.
