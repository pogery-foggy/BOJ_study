# 조합론 핵심

## 1. 한 문장 기억

순서를 무시한 선택은 `nCk`로 모델링하고, 범위에 따라 팩토리얼·파스칼 DP·모듈러 역원 중 안전한 계산법을 고른다.

## 2. 언제 꺼내는가

- n개 중 k개를 순서 없이 선택하는 경우의 수를 묻는다.
- 배열, 격자 경로, 이항계수 점화식으로 환원된다.
- 중복 선택인지, 순서가 있는지부터 구분해야 한다.

## 3. 핵심 상태 / 불변식

- `C(n,k) = C(n-1,k-1) + C(n-1,k)`.
- 경계는 `C(n,0)=C(n,n)=1`이고 대칭성 `C(n,k)=C(n,n-k)`가 있다.
- 작은 입력에서만 `n!/(k!(n-k)!)`를 정수형으로 직접 계산해도 안전하다.

## 4. C++ 최소 구현 골격

```cpp
long long comb[101][101]{};
for (int n = 0; n <= N; ++n) {
    comb[n][0] = comb[n][n] = 1;
    for (int k = 1; k < n; ++k) {
        comb[n][k] = comb[n - 1][k - 1] + comb[n - 1][k];
        // 모듈러 문제라면 여기서 %= MOD
    }
}
cout << comb[N][K];
```

## 5. 빈 화면 구현 순서

1. 순서가 결과를 바꾸는지, 같은 원소를 다시 뽑는지 확인한다.
2. 답의 최대 크기와 모듈러 유무를 확인한다.
3. 작은 범위면 곱셈식, 일반 범위면 파스칼 DP를 고른다.
4. `k=0`, `k=n` 기저를 먼저 초기화한다.
5. 작은 n의 파스칼 삼각형을 손으로 대조한다.

## 6. 자주 틀리는 지점

- 중간 팩토리얼이 최종 답보다 훨씬 먼저 overflow하는 점을 놓치는 실수.
- 모듈러 나눗셈을 일반 정수 나눗셈처럼 처리하는 실수.
- 순열과 조합, 중복조합을 혼동하는 실수.
- DP 초기화 없이 0행·대각선 값을 참조하는 실수.
