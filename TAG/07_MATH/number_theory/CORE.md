# 정수론 핵심

## 1. 한 문장 기억

정수의 나눗셈 구조를 gcd·배수·소인수로 바꾸면 큰 범위도 규칙 단위로 건너뛸 수 있다.

## 2. 언제 꺼내는가

- 최대공약수·최소공배수·약수·배수 관계가 답을 결정한다.
- 구간 전체에서 특정 제곱수나 소수의 배수를 지워야 한다.
- 반복되는 절단·동기화 지점의 개수가 gcd로 합쳐진다.

## 3. 핵심 상태 / 불변식

- 유클리드 호제법에서 `gcd(a,b) = gcd(b,a%b)`이고 나머지가 0일 때 b가 답이다.
- `lcm(a,b) = a/gcd(a,b)*b`; 먼저 나눠 overflow 위험을 줄인다.
- 구간 체에서 배수 `p`의 첫 위치는 `ceil(L/p)*p = ((L+p-1)/p)*p`다.

## 4. C++ 최소 구현 골격

```cpp
long long gcd(long long a, long long b) {
    while (b) {
        long long r = a % b;
        a = b;
        b = r;
    }
    return a;
}

long long lcm(long long a, long long b) {
    return a / gcd(a, b) * b;
}

// [L,R]에서 어떤 p의 배수 표시
long long first = (L + p - 1) / p * p;
for (long long x = first; x <= R; x += p) marked[x - L] = true;
```

제곱 ㄴㄴ 수에서는 `p=i*i`를 두고 `i<=sqrt(R)`까지만 같은 구간 체를 수행한다.

## 5. 빈 화면 구현 순서

1. 문제의 반복 구조를 약수·배수·gcd 관계로 표현한다.
2. 유클리드 함수와 자료형을 먼저 정한다.
3. 구간 문제면 표시 배열을 `R-L+1` 크기로 잡는다.
4. 각 배수의 첫 구간 내 위치를 올림 나눗셈으로 구한다.
5. 중복 표시는 허용하고 마지막에 한 번만 센다.
6. `L=1`, 서로소, 같은 수, 큰 곱을 검사한다.

## 6. 자주 틀리는 지점

- gcd 함수에 작은 수가 0인 경우를 고려하지 않는 실수.
- lcm에서 `a*b`를 먼저 계산해 overflow하는 실수.
- 구간 체의 인덱스를 실제 값 그대로 사용해 거대한 배열을 만드는 실수.
- `sqrt` 경계와 `i*i`를 `int`로 계산하는 실수.
