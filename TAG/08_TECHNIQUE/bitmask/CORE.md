# 비트마스크 핵심

## 1. 한 문장 기억

작은 집합의 포함 여부를 정수의 각 비트 하나에 대응시키면 검사·추가·삭제·토글을 O(1)에 할 수 있다.

## 2. 언제 꺼내는가

- 원소 수가 대략 20~60개이고 부분집합 또는 방문 상태를 통째로 저장한다.
- 여러 bool 상태를 하나의 정수로 압축한다.
- 완전이진트리 인덱스처럼 2진 표현 자체가 부모·자식 관계를 나타낸다.

## 3. 핵심 상태 / 불변식

- 원소 x를 0번 비트부터 쓰려면 입력 직후 `--x`한다.
- x가 포함됨은 `(mask & (1ULL<<x)) != 0`과 같다.
- 부모 인덱스는 `x>>1`; 비트를 하나 버릴 때마다 한 층 위로 간다.

## 4. C++ 최소 구현 골격

```cpp
uint64_t mask = 0;
auto bit = [](int x) { return 1ULL << x; };

mask |= bit(x);        // add
mask &= ~bit(x);       // remove
bool has = mask & bit(x);
mask ^= bit(x);        // toggle
mask = (1ULL << n) - 1; // all, 단 n<64
mask = 0;              // empty

for (uint64_t sub = mask; sub; sub = (sub - 1) & mask) {
    // mask의 0이 아닌 모든 부분집합
}
```

## 5. 빈 화면 구현 순서

1. 각 비트가 뜻하는 원소와 0/1 기반 인덱스를 정한다.
2. 필요한 정수 폭(`int`, `long long`, `uint64_t`)을 고른다.
3. 추가·삭제·검사·토글 식을 먼저 적는다.
4. 전체 마스크와 종료 조건을 만든다.
5. 0번째 비트와 가장 높은 비트를 시험한다.

## 6. 자주 틀리는 지점

- `1 << x`가 int에서 overflow하므로 큰 비트에는 `1ULL << x`가 필요하다.
- 삭제를 XOR로 구현해 없던 원소를 오히려 추가하는 실수.
- `&`와 `==`의 우선순위를 믿고 괄호를 생략하는 실수.
- 논리 연산 `&&`와 비트 연산 `&`를 혼동하는 실수.
