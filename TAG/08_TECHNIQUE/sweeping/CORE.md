# 스위핑 핵심

## 1. 한 문장 기억

구간의 시작과 끝을 좌표순으로 정렬한 뒤 왼쪽에서 오른쪽으로 훑으며 활성 상태만 갱신한다.

## 2. 언제 꺼내는가

- 선분 합집합 길이, 최대 겹침 수, 구간 연결 여부를 구한다.
- 사건이 좌표 순서대로 일어나며 과거 좌표로 돌아갈 필요가 없다.
- 한쪽 끝을 정렬하고 반대쪽 끝을 힙·집합으로 관리한다.

## 3. 핵심 상태 / 불변식

- 현재 사건보다 왼쪽의 모든 시작·끝은 처리 완료다.
- 이벤트 방식에서 `active`는 현재 열린 구간 수다.
- 합집합 길이는 `active`가 0→1이 된 좌표부터 1→0이 된 좌표까지 더한다.
- 같은 좌표의 시작/끝 처리 순서는 구간 포함 정의에 맞춰 고정한다.

## 내 코드 스타일 C++ 최소 구현 골격

스타일 근거: [2170.cpp](./2170.cpp)의 전역 `pair<int,int> arr[]`, 시작 `+1`/끝 `-1` 이벤트를 인접 칸에 저장, `prv`/`cur` 상태와 인덱스 `for`문을 축약했다. 원본에 없는 구조적 바인딩은 제거했다.

```cpp
pair<int, int> arr[2000000];
int N, answer, prv, cur;

void init() {
    cin >> N;
    for (int i = 0; i < N * 2; i += 2) {
        cin >> arr[i].first >> arr[i + 1].first;
        arr[i].second = 1;
        arr[i + 1].second = -1;
    }
    sort(arr, arr + N * 2);
}

void solve() {
    for (int i = 0; i < N * 2; i++) {
        if (cur == 0)
            prv = arr[i].first;
        cur += arr[i].second;
        if (cur == 0)
            answer += arr[i].first - prv;
    }
    cout << answer;
}
```

좌표 차이의 합이 `int`를 넘는 조건이면 `answer`와 `prv`만 `long long`으로 넓힌다. 최대 겹침 수는 [1689.cpp](./1689.cpp)처럼 같은 이벤트 배열에서 `cur`의 최댓값만 갱신한다.

## 5. 빈 화면 구현 순서

1. 각 구간을 `l<=r`로 정규화한다.
2. 사건을 시작 `+1`, 끝 `-1`로 만든다.
3. 같은 좌표 tie-break가 답에 미치는 영향을 정한다.
4. 좌표순으로 정렬한다.
5. `active` 전환 순간에만 답 또는 컴포넌트를 갱신한다.
6. 완전히 분리, 일부 겹침, 같은 끝점, 포함 관계를 시험한다.

## 6. 자주 틀리는 지점

- 같은 좌표의 이벤트 순서가 최대 겹침 수에 영향을 주는 것을 놓치는 실수.
- 입력 선분의 두 끝을 정규화하지 않는 실수.
- 열린 구간이 끝날 때 마지막 길이를 더하지 않는 실수.
- 길이·좌표 합을 `int`로 두는 실수.
