# 스위핑 핵심

## 1. 한 문장 기억

구간의 시작과 끝을 좌표순으로 정렬한 뒤 왼쪽에서 오른쪽으로 훑으며 활성 상태만 갱신한다.

## 2. 언제 꺼내는가

- 선분 합집합 길이, 최대 겹침 수, 구간 연결 여부를 구한다.
- 사건이 좌표 순서대로 일어나며 과거 좌표로 돌아갈 필요가 없다.
- 한쪽 끝을 정렬하고 반대쪽 끝을 힙·집합으로 관리한다.

## 3. 핵심 상태 / 불변식

- 현재 사건보다 왼쪽의 모든 시작·끝은 처리 완료다.
- 이벤트 방식에서 `active`는 현재 열린 구간 수다.
- 합집합 길이는 `active`가 0→1이 된 좌표부터 1→0이 된 좌표까지 더한다.
- 같은 좌표의 시작/끝 처리 순서는 구간 포함 정의에 맞춰 고정한다.

## 4. C++ 최소 구현 골격

```cpp
vector<pair<long long,int>> event;
for (auto [l, r] : segments) {
    if (l > r) swap(l, r);
    event.push_back({l, +1});
    event.push_back({r, -1});
}
sort(event.begin(), event.end());

long long answer = 0, start = 0;
int active = 0;
for (auto [x, delta] : event) {
    if (active == 0) start = x;
    active += delta;
    if (active == 0) answer += x - start;
}
```

## 5. 빈 화면 구현 순서

1. 각 구간을 `l<=r`로 정규화한다.
2. 사건을 시작 `+1`, 끝 `-1`로 만든다.
3. 같은 좌표 tie-break가 답에 미치는 영향을 정한다.
4. 좌표순으로 정렬한다.
5. `active` 전환 순간에만 답 또는 컴포넌트를 갱신한다.
6. 완전히 분리, 일부 겹침, 같은 끝점, 포함 관계를 시험한다.

## 6. 자주 틀리는 지점

- 같은 좌표의 이벤트 순서가 최대 겹침 수에 영향을 주는 것을 놓치는 실수.
- 입력 선분의 두 끝을 정규화하지 않는 실수.
- 열린 구간이 끝날 때 마지막 길이를 더하지 않는 실수.
- 길이·좌표 합을 `int`로 두는 실수.
