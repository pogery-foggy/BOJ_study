# 정렬 핵심

## 1. 한 문장 기억

대상을 비교 가능한 키로 바꿔 정렬하면, 원하는 순서와 인접 관계가 드러나 이후 탐색을 단순하게 만들 수 있다.

## 2. 언제 꺼내는가

- 여러 기준의 우선순위대로 출력하거나 처리한다.
- 순서가 상관없는 입력을 정렬해 인접 원소만 비교하면 된다.
- 정렬된 두 배열을 합치거나 순위를 매긴다.

## 3. 핵심 상태 / 불변식

- 비교 함수는 엄격한 약순서여야 한다. 같은 원소끼리 `true`를 반환하지 않는다.
- `pair`는 기본적으로 `first`, 같으면 `second` 순으로 정렬된다.
- 정렬 후 i 이전 구간은 최종 순서가 확정되어 있다.

## 내 코드 스타일 C++ 최소 구현 골격

스타일 근거: [11651.cpp](./11651.cpp)의 전역 `vector<pair<int,int>> arr`, 람다 대신 이름 있는 `cmp`, `init()`에서 입력과 정렬, `solve()`에서 범위 `for` 출력 구조를 축약했다.

```cpp
int N;
vector<pair<int, int>> arr;

bool cmp(pair<int, int> a, pair<int, int> b) {
    if (a.second == b.second)
        return a.first < b.first;
    return a.second < b.second;
}

void init() {
    cin >> N;
    int user_in1, user_in2;
    for (int i = 0; i < N; i++) {
        cin >> user_in1 >> user_in2;
        arr.push_back({user_in1, user_in2});
    }
    sort(arr.begin(), arr.end(), cmp);
}

void solve() {
    for (auto a : arr)
        cout << a.first << " " << a.second << "\n";
}
```

단순히 두 정렬 입력을 함께 출력하는 문제에서는 [11728.cpp](./11728.cpp)처럼 하나의 전역 벡터에 모두 넣고 `sort`한 뒤 인덱스 반복문으로 출력하기도 한다.

## 5. 빈 화면 구현 순서

1. 문제의 1순위·2순위·동률 기준을 적는다.
2. `pair`로 충분한지 별도 구조체 비교 함수가 필요한지 정한다.
3. 정렬 전 원본 순서 보존 필요 여부를 확인한다.
4. 정렬 후 한 번의 순회로 답을 만든다.
5. 모든 키가 같은 경우로 비교 함수를 검증한다.

## 6. 자주 틀리는 지점

- 비교 함수에서 `<=`를 써 정렬 계약을 깨는 실수.
- 오름차순과 내림차순 키를 한꺼번에 뒤집는 실수.
- 정렬만 하면 O((N+M)log(N+M))인데 이미 정렬된 두 배열의 O(N+M) 병합을 놓치는 경우.
- 안정 정렬이 필요한데 `sort`가 입력 순서를 보존한다고 가정하는 실수.
