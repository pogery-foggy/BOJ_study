# 누적합 핵심

## 1. 한 문장 기억

변하지 않는 배열의 구간 합을 여러 번 묻는다면, 앞에서부터 합을 한 번 저장해 두고 경계의 차로 답한다.

## 2. 언제 꺼내는가

- 정적 배열에서 구간 합·구간 내 조건 발생 횟수 질의가 많다.
- 2차원 직사각형 합을 반복해서 구한다.
- 다른 알고리즘이 정한 구간의 합을 O(1)에 평가해야 한다.

## 3. 핵심 상태 / 불변식

- 1차원 `ps[i]`는 첫 i개, 즉 `[1,i]`의 합이다. 따라서 `[l,r] = ps[r]-ps[l-1]`.
- 2차원 `ps[y][x]`는 좌상단 `(1,1)`부터 `(y,x)`까지의 합이다.
- 0행·0열을 0으로 두면 경계 분기가 사라진다.

## 내 코드 스타일 C++ 최소 구현 골격

스타일 근거: [2167.cpp](./2167.cpp)의 전역 `arr`/`prefix_sum` 2차원 배열, 1-based 반복, `init_arr`/`print_dist` 함수 분리와 `init()` → `solve()` 구조를 축약했다. 비어 있는 `11660.cpp`는 근거로 쓰지 않았다.

```cpp
int arr[301][301];
int prefix_sum[301][301];
int N, M;

void init_arr(int s_x, int e_x, int s_y, int e_y) {
    for (int i = 1; i <= N; i++) {
        for (int j = 1; j <= M; j++) {
            prefix_sum[i][j] = prefix_sum[i - 1][j]
                             + prefix_sum[i][j - 1]
                             - prefix_sum[i - 1][j - 1]
                             + arr[i][j];
        }
    }
}

void init() {
    cin >> N >> M;
    for (int i = 1; i <= N; i++)
        for (int j = 1; j <= M; j++)
            cin >> arr[i][j];
    init_arr(1, N, 1, M);
}

int print_dist(int s_x, int s_y, int e_x, int e_y) {
    return prefix_sum[e_x][e_y] - prefix_sum[e_x][s_y - 1]
         - prefix_sum[s_x - 1][e_y] + prefix_sum[s_x - 1][s_y - 1];
}
```

1차원 조건 횟수는 [21318.cpp](./21318.cpp)처럼 전역 `prefix_sum[]`에 사건을 먼저 표시한 뒤 다시 누적하고, 질의에서 두 경계의 차를 바로 출력한다. 합의 최대값이 크면 배열형만 `long long`으로 넓힌다.

`init_arr`의 네 경계 인자는 원본에서도 사용하지 않지만, 이 문서에서는 실제 함수 모양과 호출 습관을 기억할 수 있도록 그대로 남겼다. 범용 구간 초기화로 확장하려면 반복문의 시작·끝에 이 인자들을 실제로 연결해야 한다.

## 5. 빈 화면 구현 순서

1. `ps[i]`가 어디까지 포함하는지 선언한다.
2. 원본을 1번 인덱스부터 저장한다.
3. 누적 점화식을 작성한다.
4. 질의 경계를 모두 inclusive로 통일한다.
5. 빼기 두 번, 중복 제거분 더하기 한 번을 쓴다.
6. 길이 1 구간과 전체 구간을 검사한다.

## 6. 자주 틀리는 지점

- `[l,r]`에서 `ps[l]`을 빼 첫 원소를 누락하는 실수.
- 2차원에서 좌상단 중복 영역을 다시 더하지 않는 실수.
- 합을 `int`로 두어 overflow하는 실수.
- 값 갱신이 있는 문제에 정적 누적합을 쓰는 실수.
