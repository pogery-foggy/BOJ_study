# 2441번: 별 찍기 - 4

- 시간 제한: 1 초
- 메모리 제한: 128 MB
- 파일명 기반 분류 (공식 알고리즘 분류 아님): 없음
- 아카이브: [Wayback Machine에서 보기](https://web.archive.org/web/20260416150149/https://www.acmicpc.net/problem/2441)

## 문제

첫째 줄에는 별 N개, 둘째 줄에는 별 N-1개, ..., N번째 줄에는 별 1개를 찍는 문제

하지만, 오른쪽을기준으로정렬한별(예제참고)을출력하시오.

## 입력

첫째 줄에 N(1 ≤ N ≤ 100)이 주어진다.

## 출력

첫째줄부터N번째줄까지차례대로별을출력한다.
