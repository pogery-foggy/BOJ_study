# 2754번: 학점계산

- 시간 제한: 1 초
- 메모리 제한: 128 MB
- 파일명 기반 분류 (공식 알고리즘 분류 아님): 없음
- 아카이브: [Wayback Machine에서 보기](https://web.archive.org/web/20260416091814/https://www.acmicpc.net/problem/2754)

## 문제

어떤 사람의 C언어 성적이 주어졌을 때, 평점은 몇 점인지 출력하는 프로그램을 작성하시오.

A+: 4.3, A0: 4.0, A-: 3.7

B+: 3.3, B0: 3.0, B-: 2.7

C+: 2.3, C0: 2.0, C-: 1.7

D+: 1.3, D0: 1.0, D-: 0.7

F: 0.0

## 입력

첫째 줄에 C언어 성적이 주어진다. 성적은 문제에서 설명한 13가지 중 하나이다.

## 출력

첫째 줄에 C언어 평점을 출력한다.
