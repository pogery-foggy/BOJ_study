# 1676번: 팩토리얼 0의 개수

- 시간 제한: 2 초
- 메모리 제한: 128 MB
- 파일명 기반 분류 (공식 알고리즘 분류 아님): 없음
- 아카이브: [Wayback Machine에서 보기](https://web.archive.org/web/20260417025942/https://www.acmicpc.net/problem/1676)

## 문제

N!에서 뒤에서부터 처음 0이 아닌 숫자가 나올 때까지 0의 개수를 구하는 프로그램을 작성하시오.

## 입력

첫째 줄에 N이 주어진다. (0 ≤ N ≤ 500)

## 출력

첫째 줄에 구한 0의 개수를 출력한다.
