# 2443번: 별 찍기 - 6

- 시간 제한: 1 초
- 메모리 제한: 128 MB
- 파일명 기반 분류 (공식 알고리즘 분류 아님): 없음
- 아카이브: [Wayback Machine에서 보기](https://web.archive.org/web/20260416193055/https://www.acmicpc.net/problem/2443)

## 문제

첫째 줄에는 별 2×N-1개, 둘째 줄에는 별 2×N-3개, ..., N번째 줄에는 별 1개를 찍는 문제

별은 가운데를 기준으로 대칭이어야 한다.

## 입력

첫째 줄에 N(1 ≤ N ≤ 100)이 주어진다.

## 출력

첫째 줄부터 N번째 줄까지 차례대로 별을 출력한다.
